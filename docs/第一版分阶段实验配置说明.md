# 第一版分阶段实验配置说明

本文是[第一版训练与外部推理实施方案](./第一版训练与外部推理实施方案.md)的执行配置，任务限定为**增强腹部 CT 的胰腺二值分割标签质控**。原计划已经确定的数据集、网络和 60/10/20 划分在此沿用；原计划未指定的候选标签数、采样比例等，以下标为“建议初值”，实施前固定并记录到实验配置，不根据测试集或 QUBIQ 表现回改。

## 1. 总览：每阶段训练什么、用什么数据

| 阶段 | 训练/拟合对象 | 数据与比例 | 主要产物 |
|---|---|---|---|
| 0. 数据准备 | 无 | CURVAS 90 例按患者固定分为训练 60、校准 10、测试 20；QUBIQ 单独保留 | 患者清单、预处理记录、标签质检记录 |
| 1. OOF 分割 | 5 个 nnU-Net v2 `3d_fullres` 模型 | 仅 CURVAS 训练 60 例；5 折，每模型训练 48 例、留出 12 例；每例只用一份三专家多数票掩膜作监督 | 训练集 60 份 OOF 概率图；5 个折模型 |
| 2. 错误样本构造 | 无 | 仅 CURVAS 训练 60 例；每例共用其 OOF 概率图；生成真实专家、人工错误及可选 SDF 候选标签 | `(X,Y,P,三值错误监督)` 样本清单 |
| 3. 错误检测 | 两个独立的轻量 3D U-Net（MONAI `DynUNet`）：M2、M3 | 仅上述 60 例；两模型使用同一批人工错误，M3 的对照标签改为真实专家合理标签 | M2、M3 错误概率图模型 |
| 4. 校准 | 阈值、SoftMin 参数和病例级校准器；不训练两种网络 | CURVAS 校准 10 例；分割概率来自 5 模型平均 | 固定的推理与评分参数 |
| 5. 同域测试 | 无 | CURVAS 测试 20 例；参数全部固定 | M0–M3 同域结果 |
| 6. 外部推理 | 无 | QUBIQ 2021 胰腺子集：38 名患者、76 次 CT；每次两份专家标签 | 外部零样本评分与排序 |

60/10/20 指**患者数**，即 CURVAS 的 2/3、1/9、2/9；不是切片数、patch 数或专家标签数。QUBIQ 的两次扫描若来自同一患者，在统计不确定性时按患者聚类。

## 2. 阶段 0：固定数据与预处理

1. 只使用 CURVAS 的 CT 图像和胰腺标签。每位患者的三份专家标签、合成变体和缓存预测必须跟随同一患者 ID。
2. 按患者 ID 固定 60/10/20 划分，尽量平衡病例难度。保存随机种子、患者列表和数据版本；任何模型训练、早停或超参数搜索均不得读取后 30 例的标签作为训练监督。
3. 检查图像与三份标签的方向、空间尺寸、仿射矩阵和物理坐标是否对齐。图像重采样用连续插值，二值标签重采样用最近邻；错误图和概率图最终对齐到同一空间。
4. 强度截断、归一化和 spacing 按 nnU-Net 在训练折上拟合的配置执行。错误检测器读取与对应概率图严格配准的图像和标签；保存预处理参数，确保校准、测试和外部推理一致。
5. 对三位专家标签做个案级质检。明显配准错误、空掩膜或无法解释的离群标注先记录为 `UNRESOLVED`；这类病例不用于“合理差异=非错误”的监督。若必须剔除病例，应在训练前更新并重新固定划分与实际数量。

## 3. 阶段 1：训练五折 OOF 分割模型

**网络与监督。** 使用 nnU-Net v2 `3d_fullres`，输入单通道 CT，输出胰腺概率。对每例训练患者，三位专家投票至少 2 票的体素组成一份多数票分割标签。三份专家标签不可作为三个独立的训练病例，否则会让同一图像重复出现并改变患者权重。

**划分与配比。** 将 60 名训练患者固定为 5 个互斥折，每折 12 例。第 `k` 个模型只在其余 48 例上训练，随后对本折 12 例生成概率图。一个患者只接收从未用该患者训练过的模型预测，故最终有 60 份 OOF 概率图。保存**浮点概率图**，不能只保存二值结果。

**推理口径。** 后续 10 例校准、20 例同域测试和全部 QUBIQ 扫描，均使用这 5 个折模型预测后逐体素平均；不要再训练包含全部 60 例的第六个模型来替代这一步。训练患者使用单折 OOF，其他患者使用五模型平均，两者分布可能略不同，应在结果中注明。

**阶段验收。** 检查 60 个患者 ID 与各折训练 ID 没有交集；概率图与原始病例可正确反变换配准；记录五折训练和留出分割指标，仅作为分割模型健康检查，不据此触碰校准或测试标签重新训练。

## 4. 阶段 2：构造错误检测数据

对每位训练患者，令三份专家标签的逐体素票数为 `n(v)`：

- 一致核心 `C={v:n(v)=3}`；歧义带 `B={v:n(v)=1 或 2}`；专家支持范围 `U={v:n(v)≥1}`。
- `B` 中的专家差异默认是证据不足，监督记为 `-1`，不自动视作错误。
- 三值监督定义为 `1=明确错误`、`0=明确非错误`、`-1=忽略`。损失函数的 BCE 和 Dice 都只在非 `-1` 体素上计算。

**建议初值：每位训练患者固定 3 个严重人工错误候选**，分别为一致核心内局部删除、支持范围外局部添加、明显越过支持边界的扩张/偏移。以同一套错误生成规则和固定随机种子，为 M2 与 M3 生成**完全相同**的 180 个候选。变换必须改变可观察的区域；空变换、整器官消失、离谱拓扑或超出图像的候选要重新生成并记录。正例只设在可证明的错误区域；有争议的边界仍设为 `-1`。

**建议初值：每位训练患者再配 3 个非错误对照候选**，使两个模型的候选槽位相同：

| 训练集 | 人工错误槽位 | 非错误对照槽位 | 每例总数 / 60 例总数 |
|---|---:|---:|---:|
| M2：人工错误基线 | 3 个相同的人工错误 | 3 次以多数票标签作为无合成错误锚点 | 6 / 360 |
| M3：合理差异方法 | 同样的 3 个人工错误 | 3 位真实专家标签各 1 个 | 6 / 360 |

因此两个训练集的候选槽位均为**人工错误 : 非错误对照 = 1:1**；M3 中“非错误对照”是专家可接受的不同标签，M2 则没有这种多专家差异信息。多数票锚点的重复仅用于与 M3 对齐训练步数，不能当作三个独立病例；做训练/统计抽样时仍按患者计权。对真实专家标签，只有明确正确的区域给 `0`，歧义带给 `-1`；不能把整张真实专家标签都赋为 `0`。若离群标签未通过质检，该槽位不用于合理监督，并在两个模型中对称地移除对应对照槽位，以维持可比性。

**SDF 插值是可选扩充，不并入主对照。** 主实验先只用三份真实专家标签得到 M3。若插值掩膜通过边界、连通性、体积和支持范围检查，可单独做 `M3+SDF` 消融：建议每例最多 1 个，把一个真实专家对照槽位替换为该插值标签，保持 3 个对照槽位与 1:1 配比不变；同时保留不替换的 M3 主结果。未通过检查则不使用，不能按“合理标签”强行监督。

每个候选记录患者 ID、来源类型、错误类型/严重度、随机种子、对应概率图路径、有效监督体素数和质检状态。三值监督的 `0`/`1` 体素数量会因候选不同而变化，不能把“候选 1:1”误写成“正负体素 1:1”。

## 5. 阶段 3：训练错误检测器 M2 与 M3

**网络。** 两个实验均使用同一轻量 3D U-Net 架构，例如 MONAI `DynUNet`，建议输入 `[X,Y,P]` 三通道、输出单通道错误概率图、基础通道数 16。损失使用屏蔽 `-1` 的 BCE + Dice。分割网络与其缓存概率全部冻结，错误检测损失不得更新分割模型。

**训练配比建议初值。** 以患者均衡抽样，避免体积大或候选多的病例被过采样。每个训练轮次，对每位患者读取 3 个人工错误槽位和 3 个对照槽位，即两模型各 360 次候选访问；每种人工错误约占人工错误槽位的 1/3。对每个候选抽取相同数量的 3D patch，建议 patch 中 50% 围绕人工错误/疑似边界区域、25% 围绕专家歧义边界、25% 随机取器官及背景上下文。对于无人工错误的对照候选，第一类 patch 使用与该患者对应人工错误槽位的中心坐标，避免只取容易背景。patch 尺寸、batch size、训练轮数、优化器、增强、随机种子和停止规则在 M2/M3 间保持一致，并记录最终实际采样数。

为保证对照公平，**M2 和 M3 的人工错误患者、位置、严重度和访问次数逐项一致**。两者的主要差异只有对照候选从多数票锚点变成真实专家标签，以及由此产生的合理差异监督。若为处理无效监督体素而跳过某个 patch，应在两模型中按相同规则补抽。

**不利用校准集早停。** 可预先固定训练轮数，或只在 60 例训练患者内部建立用于早停的患者级内部验证划分；内部验证不能破坏用于生成概率图的 OOF 关系。10 例校准集留给最终阈值与病例评分校准，不参与网络权重选择。模型检查点及所有训练参数一起封存。

## 6. 阶段 4：校准与非学习基线

对 10 例 CURVAS 校准患者，五个分割模型平均得到 `P_cal`。每例可使用 3 份真实专家标签，以及按训练阶段已固定的规则产生的**建议 3 个严重人工错误候选**，即建议初值共 30 个真实专家候选和 30 个人工错误候选。这些样本只用于选择以下参数，不更新 nnU-Net 或错误检测器权重：

- M0：从 OOF 风格分割概率计算病例级 SoftMin 基线，在此处选定聚合参数。校准/测试使用五模型平均概率，其来源应准确记录。
- M1：从候选标签与分割概率的不一致得到错误图，校准不一致阈值、最小连通区域等规则。
- M2/M3：校准错误图阈值；在有效区域对 `1−错误概率` 做 SoftMin 聚合，并据区域特征拟合病例级 `P_err`。M0 与 M2/M3 的 SoftMin 输入不同，应分别命名、分别保存参数。

校准集仅 10 例，病例级校准器应保持简单并限制自由参数；选择规则和阈值在访问测试集前冻结。按患者统计结果，不能把 60 个候选标签当作 60 位独立患者。

## 7. 阶段 5：CURVAS 同域测试

对 20 例测试患者使用同一五模型平均概率与固定参数。建议每例测试 3 份真实专家标签和同规则的 3 个严重人工错误候选，即 60 个真实专家候选、60 个人工错误候选。所有方法 M0–M3 使用**同一批患者、候选和错误严重度**。

报告真实专家标签的误报率、严重人工错误召回率、明确监督体素上的 AUPRC、区域级召回，以及固定复核预算下的 Precision@K / Recall@K。主比较是 `FPR_reasonable(M3) < FPR_reasonable(M2)`，同时严重错误召回不能明显下降。阈值一旦在校准阶段固定，不因测试结果重新选取。统计区间或重抽样按患者聚类；若报告候选级比例，还需给出患者级汇总。

## 8. 阶段 6：QUBIQ 外部零样本推理

将 76 次 CT 按训练时的图像处理规则预处理，五个分割模型求平均得到 `P_ext`。每次扫描的两份专家标签分别作为候选 `Y_ext` 输入冻结的 M0–M3 评分流程，建议总计 152 个真实候选。QUBIQ 不参与网络训练、微调、阈值或校准器选择；外部预测称为 `P_ext`，不是 QUBIQ 上的 OOF 预测。

如需比较“真实专家标签与人工错误版本”的排序，可在**固定所有模型和阈值后**，为每份专家标签按预先写定的同类三种几何错误各造一份：建议初值为 152 个真实候选 + 456 个人工错误候选，即真实 : 人工错误 = 1:3。外部数据只有两份专家标注，不能用其并集/交集冒充稳定的三专家合理范围；人工错误评价宜采用已知施加的扰动及配对排序，不能把两位专家之间的差异直接当作错误真值。

外部结果按 38 名患者汇总或聚类，并同时展示 76 次扫描的分布。重点报告真实标签与其人工错误版本的配对排序、固定阈值下的报警率及跨域性能变化；不要借 QUBIQ 表现回调任何参数。

| 配置项 | 第一版取值/原则 | 来源 |
|---|---|---|
| CURVAS 患者划分 | 60 训练 / 10 校准 / 20 测试 | 原计划固定 |
| 分割网络 | nnU-Net v2 `3d_fullres`；5 折、每折 48/12 | 原计划固定 |
| 分割监督 | 每患者 1 份三专家多数票胰腺掩膜 | 原计划固定 |
| 错误检测网络 | MONAI `DynUNet`；输入 `[X,Y,P]`；1 个输出通道；基础通道 16 | 原计划建议 |
| 训练候选配比 | M2/M3 各 3 人工错误 + 3 对照 / 患者；共 1:1 | 本文建议初值 |
